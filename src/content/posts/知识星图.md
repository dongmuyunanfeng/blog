### 功能：

- **📚 文件自动解析成知识点**：上传 PDF / Markdown / Word / 图片等文件，后端抽取知识点，按「领域（domain）」自动聚类。
- **🌌 深空星图可视化**：前端以深空星图形式呈现个人知识体系，点击星点即可查看对应知识点详情。
- **🤖 Agent 智能体**：内置对话问答、学习规划、知识补全建议、简历生成等多个智能体能力。
- **🔍 知识点检索**：关键词检索知识点，支持搜索历史记录。
- **📝 项目经历与简历润色**：根据知识库自动生成项目经历，并提供简历润色能力。
- **🔐 前后端分离 + JWT 认证**：REST API 通信，除登录注册外接口均需 Token 鉴权，AI 对话支持 SSE 流式返回。

### 技术栈：

| 模块 | 技术 |
| --- | --- |
| 前端 | Vue 3、Vite 5、TypeScript、Vue Router、Pinia、Element Plus、ECharts、Axios |

### 快速开始：

```bash
# 1. 初始化数据库（MySQL）
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS knowledge_star_map DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
for f in 星图后端/src/main/resources/db/migration/V*.sql; do mysql -u root -p knowledge_star_map < "$f"; done

# 2. 配置 AI API Key（可选，不配则 AI 接口不可用）
export API_KEY_1=你的key   # 文件解析 → 生成知识点
export API_KEY_2=你的key   # Agent 对话 / 学习规划 / 简历生成
export API_KEY_3=你的key   # 图片 OCR 文字识别

# 3. 启动 Redis
redis-server

# 4. 启动后端（:8080）
cd 星图后端 && mvn spring-boot:run

# 5. 启动前端（:3000）
cd 星图前端 && npm install && npm run dev
```

浏览器访问 <http://localhost:3000>。
